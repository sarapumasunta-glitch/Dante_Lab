# 🚀 DANTE LAB — Actualizar en Netlify

Esta es la nueva versión con diseño de juego: mascota Dante, mundos, cartas
coleccionables, niveles, retos y fotos reales de cada descubrimiento.

## Cómo publicar (arrastrar)
1. Descarga y descomprime `dante-lab.zip` → obtienes la carpeta `dante-final`.
2. Ve a **app.netlify.com** → entra a tu proyecto (o crea uno con "Add new project").
3. En la pestaña **Deploys**, arrastra la **carpeta completa** a la zona de
   "Drag and drop". (O usa app.netlify.com/drop para uno nuevo.)
4. En segundos queda publicado. Si es el mismo proyecto, la puerta (el enlace) no cambia.

> ⚠️ Sube la carpeta completa con TODOS los archivos: index.html, data.js,
> photos.js, app.js, las imágenes y el manifest. Si falta uno, algo no se verá.

## Ponerle nombre bonito
Project configuration → Change site name → `dante-lab`
→ queda **https://dante-lab.netlify.app**

## Instalar en el iPhone de Dante
Safari → abrir el enlace → Compartir (↑) → "Añadir a pantalla de inicio" →
nombre **DANTE LAB** → Añadir. Aparece el ícono del robot Dante.

## Sobre las fotos reales
Cada descubrimiento intenta cargar una foto real (de Wikimedia, libre de derechos)
cuando hay internet. Si no hay conexión, muestra una ilustración de respaldo, así
Dante nunca ve una pantalla rota. La etiqueta "📷 foto real" aparece cuando cargó
la foto verdadera.

## Actualizar más adelante
Vuelve a arrastrar la carpeta al mismo proyecto. El enlace y el ícono de Dante
no cambian: tú mejoras, él abre el mismo ícono y descubre lo nuevo.
